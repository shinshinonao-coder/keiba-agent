KEIBA AGENT Ver.1.2.1（操作簡略化・品質改善）

・ランキング初期設定：通算 × 全券種。期間と券種は選択式。
・競馬情報スナップショットと仮想予想の手動登録は折りたたみ、通常画面はランキング中心。
・手動登録はレース名・予算など選択式（開催日未登録のレースは登録不可）。
・開催日が過去のレースの新規登録と同一AI/レース/券種の重複を防止。
・記録削除を廃止し無効化履歴を保持（無効化記録は集計対象外）。
・旧バージョンの端末内データを同じlocalStorageキーで読み込み。

注意：AIによる予想生成、公式出走表・オッズ・結果の自動取得、払戻の自動照合、学習、クラウド同期は未実装。管理者用の払戻入力は手動のままです。過去に記録されたデータの正確性は保証しません。端末内のlocalStorageは消去すると失われるため更新前にJSONバックアップを保存してください。

GitHub Pagesのリポジトリ直下の index.html と sw.js を更新。manifest.webmanifestは変更なし。
