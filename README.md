# KEIBA AGENT Ver.1.1

Ver.1.0からの更新。④競馬情報スナップショットでレース名をGⅠ/GⅡ/GⅢから選択し、開催年度を選択できるように変更。登録済み日程は自動入力。未登録日程は推測せず、公式発表を確認した場合のみ手動入力可能。

## iPhoneでの更新
GitHubの `keiba-agent` リポジトリのルートにある `index.html` と `sw.js` をこのZIPの同名ファイルで置き換える。`manifest.webmanifest` は変更不要。GitHub Pagesの公開完了後、Safariでアプリを再読み込み。

## 注意
- 2026年11月の6レース以外の日程データは未登録。GⅠ/GⅡ/GⅢのレース一覧は選択用の初期カタログであり、年度ごとの施行有無・格付けを保証しない。
- 競馬情報の自動取得、JRA公式日程の自動同期、AI予想は未実装。
- 保存キー `keiba_agent_v09` を維持し、既存のプロフィール・履歴・スナップショットを引き継ぐ。更新前のJSONバックアップを推奨。
- 日程やレース名はJRAの最新公式発表と照合すること。
