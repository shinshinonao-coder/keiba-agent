# KEIBA AGENT Ver.0.9

## 実装済み
- iPhone / Androidブラウザ向けPWAの基本構成
- プロフィール（予算、予想スタイル、好みの券種）の端末内保存
- JRAの通常8券種とWIN5の買い目組み合わせ生成
- BOX、流し、マルチ、フォーメーション、通常指定（券種により選択可能）
- 重複除去、購入額、予算チェック、手入力オッズによる想定払戻計算
- 買い目履歴の端末内保存とJSONエクスポート／インポート

## 未実装
- クラウド認証、ユーザー間同期、DBへの自動保存
- 正規の競馬データ取得・リアルタイムオッズ
- AI予想、モデル再学習、検証パイプライン
- 実際の馬券購入、決済

## iPhoneで使う
HTTPSの静的ホスティング（GitHub Pages、Cloudflare Pagesなど）へこのフォルダを配置し、Safariで公開URLを開いて「ホーム画面に追加」。ローカルファイルを直接開くだけではPWAとしてインストールできません。

## 留意点
- この試作版は馬番の存在・出走取消・枠番と馬番の対応・発売条件を外部データで検証しません。
- WIN5は `1,2/3,4/5/6,7/8` の形式で5レースを指定。
- フォーメーションの順不同券種は重複を正規化します。
- 枠連の同枠組み合わせなどは実際の成立・発売条件を別途確認してください。
- オッズ欄は手入力であり自動取得ではありません。
