# KEIBA AGENT Ver.1.0

## 追加機能
- レース別の競馬情報スナップショット（確認日時、開催日、情報種別、出典URL、事実、予想への影響）
- 同じレース・情報種別の前回記録との比較表示
- スナップショットのCSV出力、JSONバックアップへの統合
- Ver.0.9と同じlocalStorageキーを使用してプロフィール・履歴を引き継ぐ
- PWAキャッシュをv1.0へ更新

## 公開方法（iPhone / GitHub Pages）
1. リポジトリの `main` ブランチの一番上に `index.html`, `manifest.webmanifest`, `sw.js` を上書きアップロード。ZIPそのものや親フォルダを置かない。
2. GitHub Actions の Pages デプロイが完了したら公開URLを開く。ホーム画面アプリは通常再インストール不要。反映されない場合はSafariで再読み込み。
3. 念のため更新前に旧アプリの「データを書き出す」でバックアップ。Safariとホーム画面アプリでは保存領域が異なる場合がある。

## 重要な制限
- 競馬情報はユーザーによる手入力。JRAデータ、騎手、過去走、オッズの自動取得・自動照合は未実装。
- AI予想、クラウド同期、他ユーザーとの共有、馬券購入は未実装。
- 入力した出典URLや内容の正確性は自動検証しない。
- 現行の買い目生成は番号の実在や発売条件を確認しない。
